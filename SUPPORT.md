# Support

## Getting help

Use GitHub Issues for:

- installation or connection problems;
- reproducible gameplay bugs;
- feature requests;
- privacy or licensing questions.

https://github.com/lieng618/dbx-mini-games/issues

When reporting a connection problem, include:

- DBX version;
- operating system;
- the visible error message;
- whether `https://1.92.64.227/healthz` opens successfully;
- the approximate time of the failure.

Do not post credentials, tokens, private keys, or complete access logs.

## Security reports

If you find a security issue, avoid posting exploit details publicly. Open a
minimal Issue asking for a private reporting channel, without including secrets
or a working exploit.
